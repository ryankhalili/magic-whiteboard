# Commercial distribution audit

Audited 2026-09-26. This is an engineering review of installed production package metadata, package notices, and bundled math-font metadata. It covers the prototype and the replacement dependency tree. API service agreements, uploaded homework rights, trademarks, and app-store requirements are separate from software dependency licenses.

## Replacement tree status

The owned-canvas branch removes `tldraw` and all `@tldraw/*` dependencies. The new installed production tree has **119 package instances / 115 unique name-version pairs**: MIT 104, ISC 7, Apache-2.0 5, BSD-3-Clause 1, MIT AND Zlib 1, and 0BSD 1. No bespoke SDK, GPL-family, or noncommercial license identifier remains in that metadata inventory. The font OFL conditions and `@arnog/colors` notice-provenance gap below remain relevant.

[Current inventory](production-license-inventory.json) and [third-party notices](../THIRD_PARTY_NOTICES.txt) are generated by `python research/generate-notices.py` after `npm ci`. The notices are also copied to `public/THIRD_PARTY_NOTICES.txt` for inclusion in the built web app. They contain full installed license texts, Apache NOTICE material, pako's zlib notice, and OFL text with actual font attribution. The original audit below explains the replacement decision.

## Decision

The prototype's **tldraw 5.4.2, @tldraw/editor 5.4.2, and @tldraw/driver 5.4.2 require replacement** to satisfy the requested app without a commercial SDK license. Their installed license files point to tldraw's bespoke terms. The version-matched license permits development but excludes production without a separate grant, and prohibits interference with license enforcement. Removing a watermark, forking the same restricted code, or changing our app's license does not remove those conditions. Build the replacement independently and migrate saved document data. [tldraw 5.4.2 license](https://raw.githubusercontent.com/tldraw/tldraw/v5.4.2/LICENSE.md)

tldraw's current documentation requires a production license: a time-limited trial, a commercial agreement, or a discretionary noncommercial hobby license. A hobby license does not clear a commercial product. [Official licensing guide](https://tldraw.dev/community/license)

Other installed `@tldraw` packages (`state`, `state-react`, `store`, `tlschema`, `utils`, `validate`) explicitly carry MIT locally. Do not describe all packages under that scope as commercially prohibited. Removing the complete SDK dependency also removes these unnecessary implementation dependencies.

## Commercially usable does not mean notice-free

- **MIT/ISC/BSD:** commercial use and proprietary distribution are permitted with applicable copyright, license and disclaimer preservation. BSD-3-Clause also restricts use of contributor names for endorsement. [MIT text](https://opensource.org/license/mit), [Lucide's ISC and Feather MIT notices](https://lucide.dev/license)
- **Apache-2.0:** retain the license and applicable NOTICE material, preserve relevant source notices, and mark modified files when redistributing modified sources. This does not require opening our application source. `mathjs/NOTICE` identifies Jos de Jong; installed OpenAI SDK packages include root 6.49.0 and nested 7.23.0 copies. [Apache license](https://www.apache.org/licenses/LICENSE-2.0)
- **pako 1.0.11:** preserve both its MIT notice and the zlib notice in `lib/zlib/README`, including port and original authors. The zlib terms permit commercial use but require honest origin attribution and marking altered source. [Version-matched zlib notice](https://github.com/nodeca/pako/blob/1.0.11/lib/zlib/README)
- **Math fonts:** 60 inspected TTF/WOFF2 files in KaTeX and MathLive explicitly identify **SIL OFL 1.1**, copyright Design Science and Khan Academy, and reserved `KaTeX_*` font names. See [extracted binary metadata](font-license-metadata.json). Include the complete OFL and these notices; distribute unmodified fonts under OFL. Bundling and embedding in a commercial app is permitted. Selling fonts alone and using reserved names for modified fonts are restricted. These font conditions do not apply to documents created with them or require licensing the application under OFL. [Official OFL text](https://openfontlicense.org/open-font-license-official-text/)

The archived font-tooling repository's MIT license is not a substitute for the license embedded in the actual font files. [Font repository license](https://github.com/KaTeX/katex-fonts/blob/master/LICENSE)

## Notice collection gaps and release actions

Four original packages lack a top-level LICENSE/NOTICE file: `seedrandom` supplies its full MIT text in README; `javascript-natural-sort` supplies its MIT author header in source; `react-remove-scroll-bar` has an [upstream MIT license](https://github.com/theKashey/react-remove-scroll-bar/blob/master/LICENSE) and is absent from the replacement tree. `@arnog/colors` 0.5.0 declares MIT in both its installed package and official npm metadata, but its listed upstream repository was unavailable during review. Its packaged README and distribution files contain no copyright text; registry metadata identifies the publisher but does not supply a copyright notice. Preserve the available declaration and resolve that copyright/license-text provenance before a commercial release if the package remains. This is a notice gap, not evidence of a noncommercial restriction.

1. Complete the independent canvas replacement, remove SDK imports and package dependencies, and test existing notebook migration without overwriting unreadable data.
2. Generate a new production inventory from the final lockfile. Ship a third-party-notices artifact with exact installed notices, Apache NOTICE material, pako's zlib notice and font OFL notices. Do not rely only on this summary.
3. Serve notices with the deployed app and include them in downloaded distribution packages. Keep third-party licenses separate from our application's proprietary license.
4. Re-run the audit when upgrading dependencies or adding fonts, icons, templates or other assets. Declared metadata alone is insufficient for final shipped-asset review.
